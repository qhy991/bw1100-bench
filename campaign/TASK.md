# Frozen independent Bench search

Optimize only the task in campaign/groups/c.json using the fixed Compiler in
.deps/cake-ir. Read campaign/binding.json, protocol.json, intake.json and deadline.json.
The original reference, 16 workload UUIDs, ten fresh correctness rounds, dtype,
precision, rounding boundaries and tolerances are fixed. The declared community
baseline is the performance denominator. There is no inherited candidate or seed.

Read root AGENTS.md, campaign/AGENTS.md, the original task definition/reference,
.deps/cake-ir/docs/IR_GUIDE.md, compiler/AUTHORING_CONTRACT.md,
docs/MULTI_REGION_MMA.md, docs/PROGRAM_MAP_FRONTEND.md and compiler/targets/gfx938.json.
Read the exact profiling skill and guide named by the intake instruction before
editing a kernel, and record the Read in campaign/JOURNAL.md. A readable path alone
is not evidence of a Read. The target operations list is not an authoring whitelist.

Use only this Run's source, declared reference, pinned Compiler documents and your
own candidate history. Do not read another Run, condition, bench-best, prior Bench
results or external kernel collections. Knowledge is the frozen plan's selection.
The host filesystem is not an isolation boundary. Read campaign/management/StateCard.json
before each proposal and after context compaction.

All custom GPU computation must be unchanged Cake emission with declared emission receipts.
Author a Schedule or use public Compiler transforms, emit with campaign/cake_bridge.py,
and retain every declared receipt. Wrappers preserve the public ABI and may use the
source-bound community calls. Native Torch/Triton/HIP math or torch.compile is not a
counted Cake solution. Never edit Compiler, evaluator, protocol or final confirmation.

Use campaign/evaluate.py --candidate PATH --id UNIQUE --cake-artifact RECEIPT
with diagnostic evidence or a specific task-related profiling skip reason. It runs
the full original numerical gate, current-input/output-ownership checks and unprofiled
paired timing with A/A controls. Each call must compute from current inputs and
preserve retained outputs and input data. Never memoize results. Keep all failures.

Before a GPU-bottleneck claim, prewarm JIT libraries and profile the actual callable
through campaign/admit.sh profile. Retain actual requested counter rows and use the
installed analyzer. Profiled durations are not speed scores. If profiling fails,
retain the receipt and state the missing evidence. Do not infer a Compiler defect
from a malformed Schedule or a generic tool error. Record reusable leads with their
original source, diagnosis, counterexamples and disposition in campaign/EVOLUTION.md.

Use only campaign/admit.sh for bounded device work on the assigned HCU. The existing
scripts/hcu_run.py owns admission and release; the queue schedules authors only.
Never use HCU0, raw GPU Docker or another allocator. Other users' activity is not
excluded. Do not reserve a GPU during authoring or CPU preparation. Keep
TRITON_F32_DEFAULT=ieee, FLA_TRIL_PRECISION=ieee and the per-Run AITER/Triton caches.

The total budget is 10800 seconds from intake, including CPU preflight, JIT, model,
queue waits, correctness, profiling, timing and final confirmation. Search stops at
9000 seconds. The last 1800 seconds belong to the owner for one fixed nomination.
Token usage is accounting only. Do not stop at the first win, reset a deadline,
restart a Run or start another task. The owner runs final_confirmation and finish;
the author must not run them. A missing or failed final result stays missing or failed.

The common assay confirms numerical and measured behavior of the fixed wrapper.
Receipt replay proves the declared source is unchanged Compiler emission; it does not
prove the wrapper executed every declared artifact. After all Bench Runs terminate,
the independent evolve owner reviews the frozen wrapper, receipt closure and rounding
chain in a separate comparison disposition. An assay-qualified Run remains pending
owner attribution and cannot automatically become a Cake win or adoption decision.
This review cannot change the nominee, reopen search or add post-budget measurements.
